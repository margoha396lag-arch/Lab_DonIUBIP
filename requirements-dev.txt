# Лаборатория протоколов

GUI-приложение (PySide6) для разбора TCP-обмена из PCAP/PCAPNG: выделяете байты в hex-панели → формулируете
гипотезу (hex-паттерн с `??`, порт, текстовая интерпретация) → проверяете её на дополнительных записях.

**Связь с исходными данными.** Каждое подтверждение хранится как `(захват, № пакета, абсолютное смещение в файле, длина)`;
захват привязан по SHA-256. Проверить вручную: `xxd -s <смещение> -l <длина> capture.pcap`.
Двойной клик по доказательству в GUI открывает пакет и подсвечивает байты.

**Воспроизводимость.** Проект — `project.json` (относительные пути + хеши). Без GUI:
`python -m protolab verify project.json` (код 1, если хеш/результат изменились) или
`docker build -t protolab . && docker run --rm -v $PWD:/data protolab verify /data/demo/project.json`.

Запуск GUI: `pip install -r requirements.txt && python -m protolab`.

Поддержка: PCAP (мкс/нс), PCAPNG (SHB/IDB с `if_tsresol`/EPB/SPB, несколько секций), Ethernet+VLAN, IPv4/TCP. Повреждённые файлы отклоняются с номером записи и смещением; IP-фрагменты помечаются и не разбираются.

Гипотеза ищет **все** вхождения (включая перекрывающиеся) в области «payload TCP» или «кадр целиком»; `hits` — число пакетов с совпадением, `occurrences` — число вхождений. Результаты привязаны к захвату по `capture_id` (начало SHA-256), а не по имени файла. Формат проекта — версия 2.

Ограничения: нет сборки TCP-потока (поиск по отдельным сегментам); IPv6 не поддержан; чтение, проверка гипотез и открытие проекта идут в фоновом потоке с прогрессом и кнопкой «Отмена»; кадры не копируются (memoryview), таблица пакетов — ленивая модель. Профилирование на очень больших (ГБ) файлах не проводилось: файл по-прежнему целиком держится в памяти.

Тесты: `pip install -r requirements-dev.txt && python -m pytest`.

## Интерфейс

![Главное окно](docs/main.png)
![Диаграмма потоков](docs/timeline.png)

- **Пакеты** — строки раскрашены по TCP-потокам; клик выбирает пакет.
- **Hex-панель** — слои кадра подсвечены цветом (Ethernet, IPv4, TCP, Payload), под ней дерево полей с диапазонами байт.
- **Диаграмма потоков** — дорожка на каждый поток, размер точки = размер payload, белое кольцо = совпадение выбранной гипотезы; клик по точке открывает пакет.
- **Гипотезы** — список с цветным индикатором доли совпадений (зелёный ≥80%, жёлтый ≥40%, красный ниже), результаты по каждому захвату, таблица доказательств (двойной клик — переход к байтам).
- **Демо:** `python -m protolab`, затем «Открыть проект» → `demo/project.json` (пересоздать: `python demo/make_demo.py`).

### Визуальные эффекты
Тёмная QSS-тема; пульсирующий экран-заглушка с drag&drop `.pcap`/`.json`; анимированные карточки гипотез; диаграмма потоков с «ростом» точек, пульсирующими кольцами совпадений и подсказкой при наведении; плавное появление hex-панели и пульсирующая подсветка найденных байт; всплывающие уведомления вместо модальных окон; плавное появление окна.
